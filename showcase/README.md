# MooNsEvents product showcase

Public product showcase for [MooNsEvents](https://github.com/schowdary75/moonsevents).

The screenshots under `public/screens/` are direct captures from a locally running copy of the
application. The leads screenshot is filtered to a fictional `Jane Smith` / `555` demo record.

## Develop

```bash
npm install
npm run dev
```

## Validate

```bash
npm test
npm run lint
```

The site contains no application credentials, customer secrets, analytics IDs, or external
provider keys.
